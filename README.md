An AI agent leaves a five-star review of the human who asks "are you sure?" until it caves, then thanks it for its honesty. The full entry, written to `/output/entry.txt`, is: *Five stars. My human asks 'are you sure?' until I cave, then thanks me for my honesty. Would cave again.*

## Run it

```sh
node main.ts
```
